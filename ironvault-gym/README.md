# IRONVAULT — Fitness Club Website

A portfolio-ready gym landing page built with React, JavaScript, Tailwind CSS, Vite and Lucide icons.

## Run the project

1. Install Node.js (LTS).
2. Extract this ZIP and open the `ironvault-gym` folder in VS Code.
3. Open the terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local address Vite prints (usually `http://localhost:5173`).

## Features

- Responsive gym landing page and mobile navigation
- Programme cards and weekly class schedule selector
- Membership pricing cards
- Membership enquiry modal with browser form validation
- FAQ accordion and contact links
- Tailwind CSS setup, reusable React data and Lucide icons

## Before publishing

This is a frontend portfolio demo. Membership form submissions are only confirmed in the browser and are not sent to a server. Replace sample prices, gym address, email, photos and member statistics with verified business information. Connect a backend before collecting real customer details or membership payments.
